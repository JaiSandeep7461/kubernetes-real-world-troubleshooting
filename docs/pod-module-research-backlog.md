# Module 01 — Pod foundations: first research screening

These are leads discovered and inspected during the first Pod-focused search. **They are not all accepted into the 150-case learning set.** A case enters the 150 only after the source, reproduction conditions, and resolution path pass the acceptance criteria in the roadmap.

Need inspect the PR and verify the fix's scope before acceptance. |

## Decisions from this screening
- Do not count search hits as validated learning cases.
- Keep Module 01 focused on Pod/container lifecycle. Move ReplicaSet hot-loop and scheduler races into their correct later modules.
- Prefer cases with concrete YAML, commands, logs, or a deterministic topology.
- Prefer fixes evidenced by a linked PR/release or maintainer-confirmed workaround.
- Next research step: inspect PR #12126 for issue #83471, PR #10675 for containerd #6080, and PR #130411 for Kubernetes #72593; then search for simpler current Pod lifecycle cases with confirmed resolutions.
